Descriptions des éléments
-------------------------
La maquette est composée d'un bati métalique. Dans le bati nous trouvons les composants électronique. Sur le plateau métalique du bati, nous retrouvons 5 bars articulés reliés entre eux. Les deux des bars du dessous sont motorisés par un servo moteur AX-12A. Le pantographe est symétrique en suivant le plan médian perpendiculaire au moteurs. Ainsi les bras du pantographe ont deux à deux les mêmes longueurs.
